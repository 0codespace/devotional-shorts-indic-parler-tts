# 💡 Pro Tips

## For Both Tools
- Run portrait 9:16 aspect ratio explicitly if the tool lets you set dimensions
- Always end with "no text, no watermark" to keep backgrounds clean for the workflow's text overlay
- Reject images where the face looks distorted — AI struggles with deity faces sometimes; regenerate

## For ChatGPT (DALL-E 3) Specifically
- Mention "Raja Ravi Varma" — DALL-E 3 knows this artist very well
- If you want more drama: append "dark vignette edges, center spotlight"
- For face quality: add "symmetrical face, correct anatomy, realistic eyes"

## For Google Gemini / Imagen 3 Specifically
- Run the same prompt TWICE → 8 variants total (4 + 4)
- Add "high CTR YouTube thumbnail" at the very end for intent-aware outputs
- Avoid "realistic photograph" — it loses the painterly style
- If colors are washed out: add "vibrant saturated colors, deep shadows"

## 🗜️ Note on Image File Size (2.8MB - 3MB)
If ChatGPT generates images that are 3MB, **do not worry!** You do not need to compress them manually.
The workflow script (`make_thumbnail.py`) automatically opens your 3MB image and re-saves it as a compressed JPEG (~300KB) before uploading to YouTube.
If you still want to ask ChatGPT to reduce size, you can add this to the end of your prompt:
`"Please compress the final image to a smaller file size, standard web quality."` (Note: DALL-E 3 usually ignores this and outputs its standard resolution anyway, which is why the workflow compresses it for you automatically!)
